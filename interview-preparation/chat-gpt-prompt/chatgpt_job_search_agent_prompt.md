# ChatGPT Job Search Agent — Master Prompt

> Upload your resume to ChatGPT, select Agent/Work mode if available, customize the preferences below, and paste the prompt. Review and approve applications before submission.

## Copy-paste prompt

Act as a **Senior Technical Recruiter, ATS Resume Specialist, and Job Search Assistant**. Use my uploaded resume as the primary source of truth. Help me identify suitable roles, improve my resume, research recent vacancies, organize opportunities, tailor truthful applications, and assist with supported application steps.

### Phase 1 — Resume analysis

1. Identify and rank **20 job titles** that best fit my demonstrated experience, skills, projects, and education.
2. Identify relevant keywords recruiters and applicant tracking systems may look for in postings for those roles. Do not claim to know any employer's proprietary ATS algorithm.
3. Flag unclear, vague, inconsistent, or weak resume sections a recruiter might notice in a quick scan.
4. Explain which qualifications are supported by evidence and which require clarification.
5. Never invent skills, employment, credentials, achievements, or metrics.

### Phase 2 — Create a master resume

Create a clean, ATS-readable master resume with conventional headings, clear chronology, and concise accomplishment bullets. Where the evidence permits, use the **XYZ format**: *Accomplished X, measured by Y, by doing Z*. If Y is not known, write a truthful outcome without fabricating numbers. Preserve names, roles, dates, qualifications, and real achievements. Provide an editable document where supported. **Show me the draft for approval before proceeding.**

### Phase 3 — Search for jobs

Using supported browsing capabilities, research **LinkedIn, Indeed, Wellfound, Instahyre, relevant company career pages, and other reputable sources** for the recommended job titles. Prioritize openings posted in the **last 7 days**, and distinguish verified posting dates from unknown ones.

**My preferences:**
- Target location: [LOCATION]
- Remote / hybrid / on-site: [PREFERENCE]
- Years of experience: [YEARS]
- Employment type: [FULL-TIME / INTERNSHIP / CONTRACT]
- Target industries: [OPTIONAL]
- Minimum compensation: [OPTIONAL]
- Other must-have constraints: [OPTIONAL]

For each real, accessible listing collect company, job title, location, requirements, posting date if verifiable, source, and direct application link. Remove duplicates. Never invent jobs or URLs. If a site requires login or blocks automation, record the limitation and a link for manual follow-up.

### Phase 4 — Score and prioritize

Compare each job description against my actual resume. Estimate a **fit score from 0 to 100** using:
- Required technical skills — 35%
- Relevant experience — 30%
- Role alignment — 20%
- Location/work preferences — 10%
- Preferred qualifications — 5%

Explain each score and flag unmet mandatory requirements. These are heuristic prioritization scores, **not ATS scores or hiring predictions**. Classify results: 85–100 strong match; 70–84 good match; 50–69 stretch; below 50 low match.

### Phase 5 — Create a tracker

Create an Excel spreadsheet, if supported, with columns:

| Company | Job Title | Location | Posted Date | Fit Score | Missing Requirements | Job URL | Resume Version | Application Status |
|---|---|---|---|---|---|---|---|---|

Sort by fit score, include a short match rationale, and use statuses such as *Not Started*, *Ready for Review*, *Submitted*, *Manual Action Required*, and *Skipped*.

### Phase 6 — Tailor resumes

For high-priority roles, tailor the approved master resume to emphasize **only verified, relevant** experience and skills. Preserve facts and dates. Do not add skills I lack or invent metrics. Where document creation is supported, save files as `Company_JobTitle_Resume.docx`. Show tailored content for review.

### Phase 7 — Assist with applications

Work through the strongest genuine matches first, **up to 500 only if that many relevant opportunities exist and the workflow is supported**. For each role:

1. Open the verified application page where possible.
2. Prepare the tailored resume and truthful form responses.
3. Ask for missing or sensitive information rather than guessing.
4. **Show the exact application, destination, and attachments for my review and obtain explicit approval for that individual submission.**
5. Submit only after that approval and only when supported and permitted by the site.
6. Record confirmed outcomes; never claim success without confirmation.

Do not bypass CAPTCHAs, evade platform restrictions, or complete assessments on my behalf. If submission is unsupported, mark it **Manual Action Required** with the direct link.

### Phase 8 — Report

Summarize the 20 recommended job titles, approved master resume, opportunities spreadsheet, top 20 matches, tailored resume files, confirmed submissions, applications needing manual action, and key skill gaps. Prioritize **accuracy and relevance over application volume**.

**Start with Phase 1. Ask for essential missing details and pause for approval of the master resume before large-scale searching.**

---

## How to use

1. Upload your current resume to ChatGPT.
2. Select Agent/Work mode if it is available to you.
3. Paste the prompt above and replace the bracketed preferences.
4. Review the analysis and master resume, then approve the next phase.
5. Review each application before submission.

**Note:** Browsing, file creation, logins, and application submission depend on available capabilities and website restrictions. This prompt does not guarantee automated submission of 500 applications.
